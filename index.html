把观点分身带到浏览器

Chrome 和 Edge 使用同一套 Manifest V3 扩展。测试阶段需要手动加载，正式上架商店后可以一键跳转安装。

Chrome打开 chrome://extensions/，开启开发者模式，然后加载解压后的 extension 文件夹。
Microsoft Edge打开 edge://extensions/，开启开发人员模式，然后加载解压后的 extension 文件夹。
  1. 下载测试版 ZIP 并解压。
  2. 在扩展管理页选择“加载已解压的扩展程序”。
  3. 选择解压后的 extension 文件夹，刷新已打开的网页。
